# ZHANDI - 战术FPS游戏

基于Web的多人战术射击游戏，使用Three.js、Rapier物理引擎和WebSocket实现。

## 技术栈

- **渲染引擎**: Three.js
- **物理引擎**: Rapier3D (WASM)
- **网络通信**: WebSocket
- **构建工具**: Vite
- **编程语言**: TypeScript

## 功能特性

### 阶段0：基础框架 ✅
- WASM加载Rapier物理引擎
- 第一人称视角+行走跳跃
- WebSocket测试房间
- 资源管线验证
- 性能预算基线

### 阶段1：武器系统 ✅
- 4把代表武器配置（突击步枪/冲锋枪/机枪/栓狙）
- 射击/后坐力/散布/换弹/弹道
- 命中反馈与伤害模型（四肢/躯干/头部）
- 血量与消耗战系统
- AI靶子（巡逻bot）
- HUD（血量/弹药/准星/击杀提示/小地图）

### 阶段2：地图与音效 ✅
- 基础地图 - 柏林废墟（120x120）
- 物理碰撞体（静态/动态/触发器）
- 出生点与重生机制
- 基础光照（方向光+点光源+阴影）
- 环境音效（枪声/爆炸/脚步/环境）
- 基础UI（主菜单/设置/计分板）

### 阶段3：多人联机 ✅
- WebSocket同步位置/动作
- 玩家状态同步（血量/弹药/武器切换）
- 网络预测与插值（客户端预测/服务器验证）
- 网络优化（包压缩/LOD/对象池）
- 反作弊与安全（验证/检测/封禁）

### 阶段4：核心玩法 ✅
- 团队死斗模式（TDM）
- 夺旗模式（CTF）
- 占点模式（DOM）
- 排位系统与段位
- 成就系统

### 阶段5：高级功能 ✅
- 战术装备（烟雾弹/闪光弹/手雷）
- 载具系统（载具驾驶/射击/物理碰撞）
- 天气系统（雨/雪/雾/沙尘暴）
- 动态天气与昼夜循环

### 阶段6：优化与发布 ✅
- 构建优化
- 性能调优
- 打包部署

## 安装与运行

### 安装依赖

```bash
npm install
```

### 开发模式

```bash
npm run dev
```

### 构建生产版本

```bash
npm run build
```

### 预览生产版本

```bash
npm run preview
```
