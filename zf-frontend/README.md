# ZHANDI - 战术FPS游戏

基于Web的多人战术射击游戏，使用Three.js、Rapier物理引擎和WebSocket实现。
当前为**功能完整可玩的 Demo 版本**（阶段 1–10 已全部完成）。

## 技术栈

- **渲染引擎**: Three.js
- **物理引擎**: Rapier3D (WASM)
- **网络通信**: WebSocket（权威服务器）
- **构建工具**: Vite
- **编程语言**: TypeScript

## 安装与运行

### 安装依赖

```bash
npm install
```

### 开发模式

```bash
npm run dev
```

### 质量检查

```bash
npm run check
```

该命令依次执行格式检查、ESLint、TypeScript 类型检查、Vitest 和生产构建。

### 固定基准场景

在开发地址后添加 `?benchmark=1`，例如：

```text
http://localhost:5173/?benchmark=1
```

基准模式使用固定随机种子、8 个 Bot、2 辆吉普和固定晴天。按 `F3` 打开性能面板，可导出性能 JSON。

当前模拟采用固定 60 Hz 时间步，渲染保持 RAF 刷新率；长帧最多追赶 5 个模拟步。Esc 或页面失焦会进入暂停状态并重置累计器，避免恢复页面时集中补帧。

### 构建生产版本

```bash
npm run build
```

### 预览生产版本

```bash
npm run preview
```

```
│   ├── assets/          # 资源加载

│   ├── input/           # 输入管理与键位绑定

│   ├── performance/     # 性能监控（面板、动态分辨率、帧预算）
│   ├── physics/         # 物理系统
│   ├── player/          # 玩家系统
│   ├── replay/          # 战局回放录制
│   ├── telemetry/       # 崩溃/错误匿名统计
│   ├── training/        # 新手训练场
│   ├── ui/              # UI系统（菜单、向导、回放/举报面板）
│   ├── vehicle/         # 载具系统
│   ├── weapons/         # 武器系统
│   ├── main.ts          # 入口文件
│   └── style.css        # 样式文件
├── server/              # 权威联机服务器（房间、模拟、压测、soak）
├── public/              # 静态资源
├── index.html           # HTML模板
├── package.json         # 项目配置
├── tsconfig.json        # TypeScript配置
└── vite.config.ts       # Vite配置
```

## 性能与网络说明

- 已配置 Vite 代码分包、特效池、可导出的实时性能监测、动态分辨率与帧预算分段。
- LOD、实例化渲染与资源流送仍属待生产化功能。
- 联机为权威战斗服务器（`server/`）：包含房间管理、权威模拟循环、负载测试与 2 小时 soak 脚本；客户端预测、远端插值与断线恢复已接入。
- 网络压缩与反作弊尚未形成完整链路，请以“当前功能状态”表为准。
